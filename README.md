# 🐶 BoarDog

צ'אטבוט קליטה חכם לפנסיוני כלבים. כשלקוח פונה בוואטסאפ, הבוט מבצע את כל
העבודה ההתחלתית במקום בעל הפנסיון: מתשאל את בעל הכלב, בודק זמינות, קובע
**פגישת היכרות** ומשריין אותה, ושולח לבעל הפנסיון סיכום מסודר.

> זהו **אב-טיפוס** — אפליקציית ווב בסגנון וואטסאפ שמדגימה את החוויה מקצה
> לקצה, לפני חיבור ל-WhatsApp Business האמיתי.

## הדגמה חיה
לאחר הפעלת GitHub Pages: `https://<user>.github.io/boardog/`

## מה יש כאן
- **ממשק צ'אט בסגנון וואטסאפ** (עברית, RTL) — בועות, "מקליד/ה…", כפתורי מענה מהיר.
- **שני מנועי שיחה:**
  - **מצב הדגמה (ברירת מחדל)** — זרימת תשאול מונחית שעובדת מיד, בלי מפתח ובלי רשת.
  - **מצב AI (Claude)** — שיחה טבעית אמיתית עם Claude ו-Tool Use: המודל אוסף את
    הפרטים, קורא ל-`get_available_slots`, מציג מועדים, ו-`book_meeting` לשריון.
- **יומן זמינות מדומה** (`assets/js/kennel.js`) — מועדי פגישות פנויים, חלקם "תפוסים".
- **כרטיס סיכום** בסוף — בדיוק מה שבעל הפנסיון מקבל.

## הפעלה מקומית
זהו אתר סטטי — כל שרת קבצים מספיק:
```bash
cd boardog
python3 -m http.server 8080
# פותחים http://localhost:8080
```

## מצב AI (Claude)
לוחצים על ⚙️ בכותרת ומחברים באחת משתי דרכים:
1. **פרוקסי (מומלץ, בלי לחשוף מפתח):** פורסים את `worker/boardog-proxy.js`
   ל-Cloudflare Workers, מגדירים סוד `ANTHROPIC_API_KEY`, ומדביקים את כתובת
   ה-Worker בשדה הפרוקסי.
2. **מפתח בדפדפן (BYOK):** מדביקים מפתח Anthropic — נשמר ב-localStorage בלבד.

לולאת ה-Tool Use רצה בצד הלקוח (הוא מריץ את הכלים מול היומן המדומה); ה-Worker
רק מעביר ל-Claude ומחזיר את תשובת המודל.

## פריסה
- **GitHub Pages:** הפעילו ב-Settings → Pages → Source: GitHub Actions.
  ה-workflow ב-`.github/workflows/pages.yml` יפרוס אוטומטית בכל push ל-main.

## שני צדדים (חולקים מאגר)
- **`index.html` — צד הלקוח:** הצ'אט שמתשאל, עונה על שאלות, קובע פגישת היכרות ומשריין תאריכי שהייה.
- **`owner.html` — אפליקציית הפנסיון:**
  - **🕒 זמינות** — בעל הפנסיון בוחר אילו ימים ושעות פנויים לפגישות היכרות (קבוע שבועי). הלקוחות רואים רק את המועדים האלה.
  - **📅 יומן** — מציג את פגישות ההיכרות (📋) ותקופות השהייה (🏠) עם שם הכלב והבעלים, לכל יום.
  - **🤖 שאל AI** — "כמה כלבים יהיו בפנסיון בין X ל-Y?" — לפי בחירת תאריכים (עובד תמיד), או בשפה חופשית עם Claude (אם מצב AI מופעל).

> באב-טיפוס שני הצדדים מסונכרנים דרך `localStorage` באותו דפדפן. במוצר אמיתי — שרת/DB משותף.

## מבנה
```
index.html                  ממשק הצ'אט (לקוח)
owner.html                  אפליקציית הפנסיון
assets/css/app.css          עיצוב (וואטסאפ + אפליקציית פנסיון)
assets/js/store.js          מאגר משותף: זמינות, פגישות, שהיות
assets/js/kennel.js         פרטי הפנסיון + FAQ + סכימת התשאול
assets/js/bot.js            מנועי השיחה (מונחה + Claude Tool Use)
assets/js/app.js            חיווט הצ'אט
assets/js/owner.js          לוגיקת אפליקציית הפנסיון
worker/boardog-proxy.js     פרוקסי Cloudflare ל-Claude
.github/workflows/pages.yml פריסה ל-GitHub Pages
```

## הדרך למוצר אמיתי (Roadmap)
1. **WhatsApp Business Platform** — חיבור מספר עסקי (Meta Cloud API או BSP כמו
   Twilio/360dialog). Webhook שמקבל הודעות, מפעיל את אותו מנוע, ומשיב.
2. **יומן אמיתי** — חיבור ל-Google Calendar של הפנסיון (זמינות + שריון אמיתי).
3. **רב-דיירות (SaaS)** — פנסיון = מספר + הגדרות + יומן משלו; מנוי חודשי.
4. **התראות לבעל הפנסיון** — סיכום ליד/פגישה בוואטסאפ או במייל.
5. **מסד נתונים** — שמירת לקוחות, כלבים ופגישות + מדיניות פרטיות.
